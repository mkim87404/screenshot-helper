# tools/

Standalone helper scripts: they aren't part of the app build and are run by hand from the repo root.

| Script | What it does | Dependencies | Run |
| --- | --- | --- | --- |
| [`generate-icon.cs`](generate-icon.cs) | Draws the app icon in code and writes `src/ScreenshotHelper.App/Assets/app.ico` (16–256 px), `app-256.png` and `.github/media/icon.png`. | .NET 10 SDK; `SkiaSharp 4.152.1` (pinned by the script's `#:package` directive, restored automatically) | `dotnet run tools/generate-icon.cs` |
| [`Capture-Window.ps1`](Capture-Window.ps1) | Captures a window of a running process (or the primary screen) to PNG at physical resolution, with its rounded corners and border matted to true transparency (two captures over white/black backdrops) — used for README screenshots and UI checks. Captures exactly what the window shows, so run the app against demo data before publishing. | PowerShell 7 on Windows (uses the built-in System.Drawing / WinForms assemblies) | `pwsh tools/Capture-Window.ps1 -ProcessName 'Screenshot Helper' -Output out.png` |
| [`Measure-Startup.ps1`](Measure-Startup.ps1) | Launches a built or published exe several times against a scratch settings folder and reports the time to its first visible window and to a usable Session tab (cold run, then warm median and minimum). **Mildly disruptive:** the window opens and closes once per run. | PowerShell 7 on Windows (built-in UI Automation) | `pwsh tools/Measure-Startup.ps1 -Exe 'src/ScreenshotHelper.App/bin/Release/net10.0-windows/Screenshot Helper.exe'` |
| [`Record-Frames.ps1`](Record-Frames.ps1) | Films the centre of the screen as fast as GDI allows while the app launches (or, with `-AttachTo`, while a running instance does something), printing per frame the window's rectangle and the brightness of its title bar, page and bottom, and optionally saving every frame — to find blank frames, flashes and window jumps. **Mildly disruptive.** | PowerShell 7 on Windows (System.Drawing) | `pwsh tools/Record-Frames.ps1 -Exe '…\Screenshot Helper.exe' -Theme Dark -SaveFrames out/frames` |
| [`Measure-TabSwitch.ps1`](Measure-TabSwitch.ps1) | Times switching between the Session, Renumber and Settings tabs with a large demo folder (default 800 shots) and 10 recent folders, after calibrating how long the UI Automation lookup itself takes (subtract it to get the app's share). **Mildly disruptive:** the window opens and its tabs are clicked; no keys are sent. | PowerShell 7 on Windows (built-in UI Automation) | `pwsh tools/Measure-TabSwitch.ps1 -Exe 'src/ScreenshotHelper.App/bin/Release/net10.0-windows/Screenshot Helper.exe'` |
| [`Capture-Tabs.ps1`](Capture-Tabs.ps1) | Captures every tab (Session, Settings, Renumber) in the light and/or dark theme, at the default or a given window size and with a chosen number of demo recent folders, for reviewing layout changes. The demo paths are in your temp folder, so the images are for review, not publishing. **Mildly disruptive.** | PowerShell 7 on Windows, `Capture-Window.ps1` | `pwsh tools/Capture-Tabs.ps1 -Exe '…\Screenshot Helper.exe' -OutDir out/tabs -Recents 8` |
| [`Record-ThemeSwitch.ps1`](Record-ThemeSwitch.ps1) | Films the main window while its theme is switched light → dark and back (via `Record-Frames.ps1 -AttachTo`), printing each switch's per-frame timeline to check for blank frames, flashes or jumps. **Mildly disruptive.** | PowerShell 7 on Windows, `Record-Frames.ps1` | `pwsh tools/Record-ThemeSwitch.ps1 -Exe '…\Screenshot Helper.exe'` |
| [`Check-SessionWindows.ps1`](Check-SessionWindows.ps1) | Drives a real session against a scratch folder and checks the windows it shows: the main window and caption box revealed only once drawn, the caption box focused (typed text lands in it), and the toast fully on screen, click-through, capture-excluded and uncovered after every event (including with the taskbar focused), "Paused" staying up until resume, and a second launch showing "already running" before falling back to "Paused". The toast is invisible to screen capture, so it's checked through Win32 (visible, not cloaked, inside a working area). **Disruptive:** about 25 s of session keys, Win+T once, and three real screenshots into the scratch folder; hands off keyboard and mouse. | PowerShell 7 on Windows | `pwsh tools/Check-SessionWindows.ps1 -Exe '…\Screenshot Helper.exe'` |
| [`toast-visibility-spike.cs`](toast-visibility-spike.cs) | Spike: a copy of the toast window (same window settings and Win32 styles, but capturable) shown and hidden 60 times over a white panel, sampling pixels to count how often it's really on screen; modes `layered`, `attributes`, `plain` compare the layered-window styles. **Mildly disruptive.** | .NET 10 SDK; Avalonia 12.1.3 (pinned by `#:package`) | `dotnet run tools/toast-visibility-spike.cs -- layered` |
| [`Update-ReadmeScreenshots.ps1`](Update-ReadmeScreenshots.ps1) | Regenerates every README image in `.github/media` from demo data: builds the app, seeds sample files on a `subst` drive, points `SCREENSHOTHELPER_HOME` at a scratch folder, drives the app with UI Automation and SendKeys, and captures each view. Cleans up everything it created, even on failure. **Disruptive:** it runs on your desktop for about a minute, so keep your hands off the keyboard and mouse. | PowerShell 7 on Windows, .NET 10 SDK, `Capture-Window.ps1` | `pwsh tools/Update-ReadmeScreenshots.ps1` |

## Dependencies

.NET scripts here are [file-based apps](https://learn.microsoft.com/dotnet/core/sdk/file-based-apps): each one declares its NuGet
packages with `#:package Name@Version` in its header, which is this folder's equivalent of a `requirements.txt`.
[`Directory.Packages.props`](Directory.Packages.props) switches off the repo's central package management for this folder so those
inline versions apply. PowerShell scripts use only what ships with PowerShell 7.

## Tips

- Set `SCREENSHOTHELPER_HOME` to a scratch folder before launching the app for screenshots or experiments, so your real settings
  aren't touched.
- For one-off screenshots with a neutral path, map a scratch folder to a drive letter first (`subst S: <folder>`, remove with
  `subst S: /d`). `Update-ReadmeScreenshots.ps1` does this for the README images.
